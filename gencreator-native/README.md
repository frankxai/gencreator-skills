# GenCreator native workflows

Private alpha source for the existing GenCreator account plugin. Creative Lab extends its three production, launch and operations skills with reference-to-commission, direct-experience, run-workflow-experiment, produce-build-story and review-and-learn.

Use the five skills in sequence for a reference-led commission, or invoke the relevant one for a bounded visual/nonvisual task. Each substantial job retains one commission ID and separate rights, validation, founder selection and release states. Python 3.10+ runs source and commission mechanics; Node 22+ runs the preserved launch/operations engines. The host model supplies judgment. Helpers do not infer truth or confer publication authority.

The existing remote MCP endpoint, transport and default prompts are preserved. No new MCP server or account binding is introduced. Local file execution, connector access and installed plugin invocation remain host capabilities that must be verified separately.

## Source and installation boundary

This folder is an isolated source addition. The repository marketplace is unchanged, so adding its existing marketplace does not install this new folder. Private account saving uses official Plugin Creator and the existing gencreator-native identity. A successful save does not prove installation or invocation. Public directory submission and production publishing are outside this change.

Existing remote operations process submitted data on GenCreator infrastructure only when that path is chosen. Prefer local helpers for private records; preserve OAuth/readiness gates for managed access.

## Checks

From this folder: `python3 -m unittest discover -s tests -v`, `node --test tests/operations.test.mjs`, and `node scripts/verify-projections.mjs`. Existing upstream file hashes are recorded in operations-provenance.json. The commission helper imports the preserved edition helper for hashing and strict JSON parsing. Real model/tool runs, browser inspection, second-provider review, account saving, installation and invocation have separate evidence receipts.

Keep private guidance projections and commission evidence out of public source. Load a private-guidance.md projection conditionally from reference-to-commission/references when the private account package supplies it. Missing machine-local taste files remain missing; never synthesize their contents or founder approval.
