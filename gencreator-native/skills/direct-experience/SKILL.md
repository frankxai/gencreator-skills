# Direct experience

## Inputs and work
Require the current commission revision, actual content, target ratios/viewports, accepted guidance and owner selection rules. Read existing brand assets and before state. Record inaccessible or stale taste documents; use only an accurately labeled current projection. Preserve founder feedback as quoted/source-linked decisions rather than inferred canon.

Author three different compositions using identical real content. Change hierarchy, material and interaction grammar, not merely color. Render each at desktop/mobile or the actual medium ratios. Specify type and fallback, composition, imagery/rights, material, motion, sound and interaction. Every effect needs a perceptual or functional purpose. Make content/actions work without decoration; account for keyboard, touch, focus, reduced motion and graphics failure.

Inspect each actual rendering. Use pairwise comparisons with concrete reasons: scan order, user action, legibility, affordance, meaning and cost. Recommend one treatment. Preserve alternatives and reasons. Where the founder owns new visual-family selection, retain `founder_selection: pending`; only build a clearly labeled provisional preview. Recommendation is not approval.

## Output and acceptance
Return three rendered links/files and their exact revision/hash, target sizes, design/motion/sound specs, pairwise critique, recommendation, rejected examples, founder feedback and the selection gate. Add implementation constraints, fallback and capture instructions.

Pass example: three inspectable desktop/mobile evidence-lens compositions using the same saved run and real limitations; the recommended inline control improves the existing hierarchy. Fail example: three text descriptions, three palette swaps, or a model taste score used as selection authority.

## Failure and boundaries
A failed generator leaves its job/charge state and a static/original alternative; do not resubmit uncertain paid work. Missing content becomes an explicitly labeled fixture and cannot pass as real product evidence. Route specialist rendering/capture through available tools and their required skills. Do not publish or promote a brand standard from an unaccepted direction.

Read [commission contract](../reference-to-commission/references/commission-contract.md) before changing state. Load [tool routing](../reference-to-commission/references/tool-routing.md) only when a connected surface is needed. Reuse the same commission ID and compare the current revision immediately before every dependent action. Keep technical validation, source rights, founder selection and release state separate.

When supplied by the private account package, read `references/private-guidance.md` from the plugin root for approved task-scoped source projections. Its approval/freshness states remain authoritative; a missing projection is a named gap.
